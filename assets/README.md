# assets

Put the official logo files here (Design section 2). The app loads them by these exact names and falls back
to the temporary glyph when a file is missing:

- `neat_logo_no_background_drop_shadow.png` — sticker (login 160 px, empty states 96 px, celebrations, countdown full screen)
- `neat_logo_no_background.png` — About, loading screen
- `neat_logo_background.png` — source for the PWA icon
- `NeatTeam-Banner.png` — wordmark (login, About)
- `NeatTeam-banner-dark.png` — wordmark with shadow + tagline (About footer)
- `neat_tile_background.png` — login pattern (6%)
- `Neatteam.jpg` — og:image

`icon.svg`, `icon-maskable.svg`, `icon-192.png`, `icon-512.png` are a **temporary** white rivet-gun silhouette on
#1C00EA, to be replaced by the drawn glyph (Design 2).

Rank badges have no files yet: the app draws a placeholder circle with each rank's first letter until Mentors
upload real badges in Ranks management (Ranks 2).
